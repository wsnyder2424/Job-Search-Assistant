# Job-Search-Assistant

A collection of AI-powered tools to help with your job search journey.

## Tools

### Career Plan Generator (`career_plan.py`)

Generates a personalized career development plan using Claude AI.

**Features:**
- Skills gap analysis
- Learning roadmap with specific resources
- Networking strategy
- Job search strategy
- Monthly milestones
- Quick wins to get started immediately
- Saves plan to a markdown file

**Usage:**
```bash
pip install -r requirements.txt
python career_plan.py
```
